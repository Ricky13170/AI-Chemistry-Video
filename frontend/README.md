# Frontend dự kiến

React + TypeScript + Vite. Chưa tạo Vite app hoặc cài dependency.

- `src/app/`: Routing, providers, application shell.
- `src/components/`: Các UI component dùng chung.
- `src/features/`: Chức năng: nhập chất (`chemicals/`), tạo video và xem kết quả (`videos/`).
- `src/lib/`: API client và utilities.
- `src/styles/`: Global styling.

Khởi tạo Vite khi bắt đầu lát cắt giao diện; không cần Next.js cho baseline này.
